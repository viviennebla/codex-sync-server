## 默认人物不可偏移的特征

- 固定 **向右侧视图**，圆润、大头小身、短四肢，抽象无性别特征。
- 奶油白头盔、淡紫体积阴影、大深色面罩、暖黄色发光眼睛与小橙色背包；不能恢复 Emoji 脸或人类男性比例。
- 默认造型**不包含万圣节装扮**；节日配件以后单独叠加。
- 角色、载具与背景分离；万圣节仍使用背景决定的两条实际道路，其他主题的车道合同不变。

## 模块与动画合同

- 固定 128 × 100 逻辑画布。**Head / Body / Backpack** 为三个独立替换槽，实际都通过 `atlas.webp` + `crop` 定位；四肢是独立图集切片，同一个骨架作动画。
- 人物分层：地面阴影 → Bike（若使用）→ 背包 / 四肢 → 身体 / 头部 → 面罩表情。角色姓名、评论气泡不被绘入图集。
- `setRiderSlots()` 保留后续安全替换入口，但 v0.1 不提供用户换装 UI，也不改变服务端用户数据。
- 状态与逻辑帧数：`idle` 4、`walk` 4、`happy` 3、`focused` 3、`tired` 3；`bike_mount` 2、`bike_ride` 6、`bike_glide` 2、`bike_brake` 2。
- **帧数是运行时离散姿态，不代表已完成相同数量的独立手绘动画 PNG**。要提升品质应先确认单角色静态画面、手脚锚点、踩踏一致性，再增补具体动作帧，避免批量生成浪费。

## 验收与后续

必须在 PR 合并前检查：

1. `npm test` 与 JS 语法检查通过；仅当前 Manifest 引用的资源能被读取，旧占位素材的 URL 返回 404。
2. 桌面与窄屏的角色轮廓和尺寸接近已确认的 1 号设计，头盔和背包不会错位。
3. 步行 / 骑行 / 滑行 / 刹车、开心 / 专注 / 疲惫可辨认；不因透明素材或遮挡丢失点击和拖动。
4. 其他四种载具维持已有实现；背景、道路、位置数据与评论气泡不受影响。
5. `prefers-reduced-motion` 正常；素材加载失败时原有 DOM 角色可回退显示。
