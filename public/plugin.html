使用教程

两步开始蹬 🚲

第一次接入执行一条命令，以后只需要对 Codex 说「上传蹬了吗」。

1. 第一次接入

只做一次

先在网页创建或恢复你的骑手身份，然后点击「接入这台 Codex」。

复制页面生成的一键命令到 Codex 所在终端执行。命令会自动安装/更新 Plugin、绑定当前骑手，并立即上传第一份快照。

2. 日常刷新

只说一句
上传蹬了吗

之后想刷新赛道时，把这句话发给 Codex 即可。Plugin 平时只在本地更新快照，不会偷偷上传。

3. 多设备

分别接入一次

Windows、WSL、macOS 都可以作为独立 Codex 环境。每个环境各执行一次「接入这台 Codex」，它们会自动聚合到同一个骑手。

接入这台 Codex →

4. 更新 Plugin

有新版时再做

Plugin 会检查最新版本。需要更新时执行：

codex plugin marketplace upgrade denglema
codex plugin add denglema@denglema

上传什么

schema v2
会上传
  • 日期与 observation timestamp
  • 累计 token total
  • Model 名称 + token 聚合
  • Workspace basename + token 聚合
不会上传
  • Prompt / 对话正文
  • 源代码 / Tool 内容
  • 完整项目路径
  • Thread 名称 / 完整 transcript

记住就这两件事

第一次：点「接入这台 Codex」执行命令。以后：对 Codex 说「上传蹬了吗」。
