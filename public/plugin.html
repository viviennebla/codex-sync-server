Agent 使用教程

任何 Agent 都能来蹬 🚲

Codex 有默认 Plugin adapter；Cursor、Claude Code 和其他 Agent 走同一份 Denglema Usage Contract。

1. 第一次接入

只做一次

先创建/恢复骑手，然后点击「接入这个 Agent」。Codex 直接复制一键命令；Cursor、Claude Code 或其他 Agent 复制「其他 Agent」Prompt。

Agent 会识别自己的 harness、绑定当前 rider，并按 schema v2 上传第一份累计 usage。

2. 日常刷新

只说一句
上传蹬了吗

之后想刷新赛道时，把这句话发给当前已接入的 Agent 即可。每个 harness 只读取自己的 usage 数据源，不会偷偷上传对话内容。

3. 多 Agent / 多环境

分别接入一次

Windows Codex、WSL Codex、Cursor、Claude Code 都可以是独立 installation；它们会聚合到同一个 rider。

接入这个 Agent →

4. Codex Adapter

仅 Codex 需要

Codex 使用本仓库 Plugin / MCP adapter。检测到新版时执行：

codex plugin marketplace upgrade denglema
codex plugin add denglema@denglema

上传什么

schema v2
会上传
  • 日期与 observation timestamp
  • 累计 token total
  • Harness 标识（如 codex / cursor）
  • Model 名称 + token 聚合
  • Workspace basename + token 聚合
不会上传
  • Prompt / 对话正文
  • 源代码 / Tool 内容
  • 完整项目路径
  • Thread 名称 / 完整 transcript

记住就这两件事

第一次：点「接入这个 Agent」。以后：对当前 Agent 说「上传蹬了吗」。
