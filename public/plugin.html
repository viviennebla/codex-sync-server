Denglema Codex Plugin

把 Codex token 蹬进赛道

首次接入会自动上传一份快照；之后只在你明确说「上传蹬了吗」时上传。

1. 接入

一次完成

在蹬了吗网页点击「接入这台 Codex」，复制页面生成的一条命令到 Codex 所在终端执行。

命令会自动安装/更新 Plugin、绑定当前骑手、fresh collect，并上传第一份 schema v2 快照。

2. 开蹬

之后只说一句
上传蹬了吗

以后需要刷新赛道时，只需要把这句话发给 Codex。pairing code 不需要用户查看或手工处理。

3. 日常上传

不会自动上传

Plugin 使用期间最多每小时刷新一份本地 latest snapshot。需要刷新赛道时，对 Codex 说：

上传蹬了吗

普通上传直接使用 latest snapshot，不重新扫描日志。

4. 更新 Plugin

版本感知

新版 Plugin 会通过 denglema_status 检查当前版本和 GitHub main 上的最新版本。检测到更新后按顺序执行：

codex plugin marketplace upgrade denglema
codex plugin add denglema@denglema

上传什么

schema v2
会上传
  • 日期与 observation timestamp
  • 累计 token total
  • Model 名称 + token 聚合
  • Workspace basename + token 聚合
不会上传
  • Prompt / 对话正文
  • 源代码 / Tool 内容
  • 完整项目路径
  • Thread 名称 / 完整 transcript

多设备

Windows、WSL、macOS 各自作为一个 installation；分别执行一次「接入这台 Codex」后，服务端按同一个 rider 聚合。
