Denglema Codex Plugin

把 Codex token 蹬进赛道

本地生成使用量快照；你明确上传时才把聚合数据发到蹬了吗。

1. 安装

Git marketplace
codex plugin marketplace add viviennebla/codex-usage-dashboard
codex plugin add denglema@denglema

安装完成后重启 Codex。首次使用会打开蹬了吗网页。

2. 绑定设备

每个环境一次
  1. 在蹬了吗里创建/恢复你的骑手身份。
  2. 点击「绑定新设备」生成 5 分钟有效的 pairing code。
  3. 在对应 Codex 环境发送：绑定蹬了吗 <pairing-code>
  4. 只有服务端返回真实 installation ID 并二次验证成功，才算绑定完成。

3. 日常上传

不会自动上传

Plugin 使用期间最多每小时刷新一份本地 latest snapshot。需要刷新赛道时，对 Codex 说：

上传蹬了吗

普通上传直接使用 latest snapshot，不重新扫描日志。

4. 更新 Plugin

版本感知

新版 Plugin 会通过 denglema_status 检查当前版本和 GitHub main 上的最新版本。检测到更新后按顺序执行：

codex plugin marketplace upgrade denglema
codex plugin add denglema@denglema

上传什么

schema v2
会上传
  • 日期与 observation timestamp
  • 累计 token total
  • Model 名称 + token 聚合
  • Workspace basename + token 聚合
不会上传
  • Prompt / 对话正文
  • 源代码 / Tool 内容
  • 完整项目路径
  • Thread 名称 / 完整 transcript

多设备

Windows、WSL、macOS 各自作为一个 installation；绑定到同一个骑手身份后，服务端按 rider 聚合。
