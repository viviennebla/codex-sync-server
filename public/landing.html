蹬了吗

把 Codex token 蹬进一条有点离谱的办公室赛道。排行榜只统计 token 数，不上传 prompt、代码或对话内容。

进入赛道打开飞书「蹬了吗」，查看今天谁蹬得最远。
→
绑定新设备打开飞书并直接进入 pairing 流程，把新的 Codex 环境绑到你的账号。
→

浏览器本身不保存你的飞书身份；个人数据只在飞书 H5 里通过飞书免登读取。

安装 Codex Plugin

在终端执行下面两条命令，然后重新启动 Codex。首次未绑定时，Plugin 会自动打开这个入口页并带你去飞书绑定。

codex plugin marketplace add viviennebla/codex-usage-dashboard
codex plugin add denglema@denglema
